# H5 / browser

Install the browser wrapper only in an internal diagnostic entry. It observes fetch/XHR, WebSocket summaries and console while preserving existing consumers and original console output.

```js
import { createInspector } from '@mobile-inspector/javascript';
import { installBrowserCapture } from '@mobile-inspector/javascript/browser';
import { mountInspectorPanel } from '@mobile-inspector/javascript/panel';
const inspector = createInspector({ app: 'Synthetic H5', platform: 'h5', environment: 'staging' });
const uninstall = installBrowserCapture(inspector);
const unmount = mountInspectorPanel(inspector);
// The panel owns explicit start/stop and pairing actions.
// On teardown:
// unmount(); uninstall(); inspector.clear(); inspector.disconnect();
```

The panel exposes scanning, confirmation, recording, filtering and explicit export. Camera decoding is bundled locally and starts only after Scan. No remote decoder or microphone is used. Scanning/configuration requires recording stopped; a changed generation cancels pending work.

On a phone, camera access needs a secure context. Ingestion requires a system-trusted HTTPS endpoint and matching browser origin policy. The desktop's default self-signed identity is not sufficient for browser trust. Supply reviewed certificate/endpoint settings rather than changing business TLS.

Wrapping the browser does not capture every application framework automatically. Validate one harmless request through your actual transport. Keep installed wrapper ownership and cleanup paired, clear/disconnect on account change, and exclude all diagnostic imports from normal release graphs.
