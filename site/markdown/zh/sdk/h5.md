# H5 / 浏览器

仅在内部诊断入口安装浏览器包装器。它观察 fetch/XHR、WebSocket 摘要与 console，同时保留原消费者和原 console 输出。

```js
import { createInspector } from '@mobile-inspector/javascript';
import { installBrowserCapture } from '@mobile-inspector/javascript/browser';
import { mountInspectorPanel } from '@mobile-inspector/javascript/panel';
const inspector = createInspector({ app: 'Synthetic H5', platform: 'h5', environment: 'staging' });
const uninstall = installBrowserCapture(inspector);
const unmount = mountInspectorPanel(inspector);
// 面板提供显式开始、停止与配对操作。
// 卸载时：
// unmount(); uninstall(); inspector.clear(); inspector.disconnect();
```

面板提供扫码、确认、记录、过滤与主动导出。摄像头只在点击扫一扫后启动，解码器随包本地提供，不使用远程服务或麦克风。扫码与配置必须保持停止，代次变化会取消待处理操作。

手机摄像头需要安全上下文，采集传输需要系统信任的 HTTPS 与匹配的浏览器来源策略。电脑默认自签身份不足以满足浏览器信任，应提供经审阅的证书与地址配置，不能改变业务 TLS。

浏览器包装不表示所有框架 Transport 都已接入。使用实际业务传输验证一次无敏感请求；安装与卸载保持成对，换号时清除并断开，普通发布依赖图排除全部诊断导入。
