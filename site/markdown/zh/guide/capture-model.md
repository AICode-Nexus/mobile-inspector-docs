# 采集模型

Mobile Inspector 观察应用已有 Transport，不替换业务传输、不二次读取流，也不负责业务重试。

## 显式生命周期

SDK 创建后保持停止。停止时配置配对并确认非秘密目标，再通过独立用户动作开始记录。开始会创建新的采集代次；停止保留有界记录，但使旧句柄和发送队列失效。清除会停止、失效回调、清空内存，并尝试清除配对远端。断开移除诊断传输配置。

换号或切换环境时，先清除并断开，再开展新工作。旧代次的迟到回调不得写入新账号。关闭面板本身不代表停止采集。

## 一次读取与观察

适配器只旁路观察业务消费者实际读取的字节。SSE 增量解析，未完成尾部丢弃。HTTP 状态、传输结束、取消与业务成功分别记录。二进制、文件与音频只保留摘要。原生日志需显式调用 SDK；JavaScript 可以包装 console 并保留原输出。

## 有界证据

默认最多保留 100 个请求、20,000 个事件和 8 MiB 序列化记录；单请求正文最多 1 MiB，SSE 帧最多 128 KiB。批次和队列也有上限。限制或缺口标记表示轨迹可能不完整。配对本身不会开启采集或诊断。

启用测试正文或导出日志前阅读[隐私说明](privacy.md)。
